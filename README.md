# Slime Crusher

A 2D platformer made with Unity.

## Goal

Make your way through a slime-infested level and defeat the giant purple slime boss before time runs out.

## Controls

| Action       | Keyboard / Mouse         | Gamepad           |
|--------------|--------------------------|-------------------|
| Move         | `A` `D` / Arrow keys     | Left stick        |
| Jump         | `Space`                  | Joystick button 3 |
| Use power-up | `Left Ctrl` / Left click | Joystick button 0 |

## Features

- **Platforming**: run, jump and stomp on enemies to defeat them
- **Power-ups**: Fire Flower to throw fireballs, Ice Flower to freeze enemies
- **Enemies**: patrolling slimes and flying slimes that dash at you
- **Boss fight**: a giant slime with a charge attack waits at the end of the level
- **Checkpoints**: respawn at the last flag you reached
- **Lives and timer**: lose all your lives or run out of time and it's game over
- **Score**: earn points from coins, enemies, power-ups and the time you have left
